Nasıl çalışır?

  1. Kullanıcı plan seçer ve ödeme yapar.
  2. Ödeme onayı ile backend hypervisor API’yi çağırır ve VM oluşturulur.
  3. Firewall politikası otomatik uygulanır (IP/NAT/VLAN).
  4. Kullanıcı panelinden başlat/durdur, şifre değiştir, konsola bağlan işlemleri yapılır.

Backend endpointleri: /api/orders, /api/vm/{id}/action, webhook: /api/webhook/payment

Hızlı notlar

  • API token + 2FA
  • Yedekler ve snapshot otomasyonu
